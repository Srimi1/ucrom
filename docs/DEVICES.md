## OnePlus 7T Pro / 7T Pro McLaren Edition

Codename `hotdog`, models HD1910 HD1911 HD1913, Snapdragon 855+, 1440x3120 AMOLED at up to 90 Hz. The McLaren Edition sold in India (HD1911, 12 GB RAM) is this same phone. The 7T Pro 5G McLaren (HD1925, `hotdogg`) has a different modem and is a separate profile.

Flavor **halium**: the LineageOS 20 kernel plus the phone's own Android 13 drivers through bridges. Each feature below is built into this image; "on hardware" becomes verified only when a Hardware Check report from a real phone confirms it.

| Feature | How ucrom drives it | Built | Verified on hardware |
|---|---|---|---|
| Touchscreen (multi-touch) | vendor kernel driver (Samsung S6SY761) | yes | pending |
| Display, brightness, screen off, 90 Hz | hwcomposer via libhybris, wlroots/phoc | yes | pending |
| GPU acceleration | Adreno via libhybris | yes | pending |
| Wi-Fi | vendor kernel qcacld-3.0 + NetworkManager | yes | pending |
| Bluetooth (audio, files; no keyboards/mice) | bluebinder + BlueZ | yes | pending |
| Calls, SMS, mobile data | ofono binder plugin + ofono2mm | yes | pending |
| Speaker, earpiece, microphone, headset | pulseaudio-modules-droid | yes | pending |
| Rear and front cameras | droidmedia + gst-droid + droidian-camera | yes | pending |
| Pop-up camera motor, drop protection | ucrom-popup-camera (sysfs motor) | yes | pending |
| In-display fingerprint unlock | droidian-fpd + ucrom-fod | yes | pending |
| Rotation, proximity, light sensors | sensorfw hybris backend | yes | pending |
| Vibration | feedbackd | yes | pending |
| Flashlight | flashlightd | yes | pending |
| NFC | nfcd + binder plugin | yes | pending |
| GPS | geoclue / modem GNSS | yes | pending |
| Battery, fast charging | vendor kernel + UPower | yes | pending |
| Alert slider (ring / vibrate / silent) | ucrom-alertslider | yes | pending |
| Power and volume buttons | vendor kernel gpio keys | yes | pending |

**Mainline fallback** (`FLAVOR=mainline`): kernel `sm8150/6.14` with ucrom's own `sm8150-oneplus-hotdog.dts`. Works today on mainline: touchscreen, boot framebuffer display, buttons, storage, USB, Wi-Fi, modem (unverified). Not yet in mainline Linux for this phone: GPU, audio, cameras, fingerprint, sensors, panel power control.
